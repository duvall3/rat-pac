OVERVIEW

PMTBASICS is a simple ROOT program demonstrating how to read PMT-hit data from a RAT-PAC output file.
Note: It is currently split into two macros (pmtBasics.cxx and drawCentroid.cxx) due to an unknown graphics error.

USAGE

Preparation (Input)

This macro is designed to extract information that RAT-PAC generates for sensitive-detector volumes. The key steps to activate this feature are as follows:
1. Ensure that your experiment’s .geo file contains sensitive_detector volumes (see $RATROOT/data/cylinder/ for an example).
2. Ensure that the simple-daq and centroid-fitter event processors are included in your event loop. You can do this by including the following lines in your RAT-PAC macro after /run/initialize and before rat/proclast:

/rat/proc simpledaq
/rat/proc fitcentroid

For convenience, a sample datafile is included here as example.root.

Running

To use pmtBasics, simply open ROOT (in this directory) and run the following two lines:

.L ./pmtBasics.cxx
pmtBasics("example.root");

Output

The macro will create an output file called example_pmtBasics.root. If it fails to run properly, you can still examine the intended output by opening the file example_pmtBasics_default.root. It should contain the following:
- a TTree called T_qt containing the extracted data
- two TCanvases, c_qt, c_r
- four histograms (three TH1F and one TH3F), ht, hq, hc, hr
See the comments in pmtBasics.cxx and drawCentroid.cxx for details on the histograms and TTree branches.

FURTHER DETAILS

Beyond the comments in these macros, you can find more general information in the RAT-PAC documentation. For specific information on the EV structure that RAT-PAC uses to store data about triggered-PMT events, see $RATROOT/src/ds/, especially the files EV.hh and MCPMT.hh.

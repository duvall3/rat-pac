◆ DumpHist()

void TDuvallUtils::DumpHist ( TH1 *  h)

Dump histogram to terminal.

Dump histogram data as (x,y) pairs to stdout, along with a rough ASCII representation of the graph.
– Primarily for use in non-graphical sessions (over ssh, for example)
– Note: Developed for use with TH1D* and TH1F* only
– Example:

TH1D* h = new TH1D("h", "h", 24, -3.5, 3.5);
h->FillRandom("gaus");
TDuvallUtils::DumpHist(h);

◆ PrintBranches()

void TDuvallUtils::PrintBranches ( TObject *  obj)

Print nicely-formatted summary of obj's TBranches.

Print a TTree's branches in a format that is easier to scan visually than TTree::GetListOfBranches()->ls().
For a full explanation of the data-type codes, see the main TTree documentation or the comments in TTree.cxx under your your $ROOTSYS directory. (On *nix systems, try find $ROOTSYS -name TTree.cxx to locate the file).
Common data types:

  • I : 32-bit signed integer (Int_t)
  • L : 64-bit signed integer (Long64_t)
  • F : 32-bit float (Float_t)
  • D : 64-bit float (Double_t)
  • C : null-terminated character string (char array, TString)
  • O : boolean (Bool_t)
  • – : compound data type (e.g., TVector3, TMatrixD, etc.)
    Parameters
    obj– TTree* or TBranch*

Double_t TDuvallUtils::UnbinnedKSTest ( TTree *  T1,
TTree *  T2,
const char *  branchName1,
const char *  branchName2 = "" 
)

Apply unbinned KS test to a pair of TBranches.

Function to execute unbinned Kolmogorov-Smirnov Test on a pair of TTrees.
Note: Branches must be of type Double_t.
See the notes in TMath::KolmogorovTest() and TH1::KolmogorovTest() for further details.

Parameters
T1,T2– input trees
branchName1– name of variable in T1
branchName2– name of variable in T2 (if different from branchName1)
Return values
P– probability that the distributions were drawn from the same parent distribution, according to the K-S Test

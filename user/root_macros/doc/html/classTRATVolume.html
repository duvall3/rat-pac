Detailed Description

Class for analyzing geometry volumes from RAT-PAC ROOT file //DOC//...//.

This class applies to individual RAT-PAC volumes. It has two primary uses:

  1. Quickly examining a single volume stored in a RAT-PAC ".root" file; and
  2. Building a complete detector geometry when called by TRATGeo.

Note: To be set properly, FindAbsolutePosition() must be run after an object is created
– This does not need to be done manually if TRATVolume objects are created by TRATGeo::Build().
Example:

TRATVolume V("water_shield");
V.FindAbsolutePosition();

Double_t TRATVolume::IBDVolRate ( Double_t  standoff,
Double_t  reactorNuRate,
Double_t  nH 
)

Volumetric IBD rate (IBD/cm^3/s) for this volume.

Determine the predicted IBD rate per cm^3 for a given standoff (baseline) from the reacor core(s), a given reactor total antineutrino flux, and a given volumetric number density of H-1 nuclei in the target material.
See ... for equivalent calculation using the reactor's thermal power instead.
Note: Assumes that the size of the reactor core(s) is/are very small compared to the standoff, so that the incoming electron-antineutrinos can be appropriately approximated by a plane wave (i.e., incident nu_ebar have uniform momentum direction).

Parameters
standoff– distance from center of detector to center of reactor core(s) (cm)
reactorNuRate– reactor's total electron-antineutrino flux (nu_e_bar/s)
nH– target material's density of H-1 nuclei (#/cm^3)
Return values
volRate– predicted volumetric rate of IBD reactions (#/cm^3/s)

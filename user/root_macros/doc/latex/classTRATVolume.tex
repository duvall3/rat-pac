\doxysubsection{Detailed Description}
Class for analyzing geometry volumes from R\+A\+T-\/\+P\+AC R\+O\+OT file //\+D\+O\+C//...//. 

This class applies to individual R\+A\+T-\/\+P\+AC volumes. It has two primary uses\+: ~\newline

\begin{DoxyEnumerate}
\item Quickly examining a single volume stored in a R\+A\+T-\/\+P\+AC \char`\"{}.\+root\char`\"{} file; and
\item Building a complete detector geometry when called by \mbox{\hyperlink{classTRATGeo}{T\+R\+A\+T\+Geo}}.
\end{DoxyEnumerate}

{\itshape Note\+:} To be set properly, \mbox{\hyperlink{classTRATVolume_afa5b832d7dc34b260fa192e71ee30d95}{Find\+Absolute\+Position()}} must be run after an object is created ~\newline
 -- This does not need to be done manually if \mbox{\hyperlink{classTRATVolume}{T\+R\+A\+T\+Volume}} objects are created by T\+R\+A\+T\+Geo\+::\+Build(). ~\newline
 Example\+: ~\newline

\end{DoxyCode}

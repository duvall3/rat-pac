\doxysubsection{Detailed Description}
Class for viewing RAT-\/\+PAC detector geometries and MC events in ROOT //\+DOC//. 

This class imports detector geometries and MC-\/event data from RAT-\/\+PAC \char`\"{}.\+root\char`\"{} output files and displays them using ROOT\textquotesingle{}s {\itshape TGeo\+Manager} system. ~\newline
 {\bfseries{Note\+: This class requires ROOT to be integrated with a working installation of RAT-\/\+PAC.}} See the \href{https://rat.readthedocs.io/en/latest}{\texttt{ RAT-\/\+PAC documentation}} for instructions. ~\newline
 Typical Usage\+: ~\newline

\begin{DoxyEnumerate}
\item Create a \mbox{\hyperlink{classTRATPACEventViewer}{TRATPACEvent\+Viewer}} object using one of the following\+: ~\newline

\begin{DoxyItemize}
\item Call the ctor with the filename and \mbox{[}optionally\mbox{]} a regex for volume selection; or ~\newline

\item Call the ctor without arguments, then call the \mbox{\hyperlink{classTRATPACEventViewer_abce2ba70242a4c9ecb485d821274a524}{Init()}} method with the filename and \mbox{[}optionally\mbox{]} a regex for volume selection. ~\newline

\end{DoxyItemize}
\item Call \mbox{\hyperlink{classTRATPACEventViewer_a64ea4bb14741b3c8e5778f1ca4993e27}{Draw\+Geometry()}}. ~\newline

\item Adjust the camera using \mbox{\hyperlink{classTRATPACEventViewer_a3386c1543eafad37d10e9a583e003453}{Zoom()}} and the mouse if desired. ~\newline

\item View at least one event using \mbox{\hyperlink{classTRATPACEventViewer_aa7ed0bc0a9f8861e21ad31999bf450b0}{Draw\+Tracks()}}. ~\newline

\item View additional events using any of \mbox{\hyperlink{classTRATPACEventViewer_aa7ed0bc0a9f8861e21ad31999bf450b0}{Draw\+Tracks()}}, \mbox{\hyperlink{classTRATPACEventViewer_a220eb5589484e59b59a903cf96486300}{Draw\+Next\+Event()}}, and \mbox{\hyperlink{classTRATPACEventViewer_a2bcdae7b7f340f5469c9b20c54c938e8}{Draw\+Prev\+Event()}}. ~\newline

\end{DoxyEnumerate}

Example, assuming a RAT-\/\+PAC output file named {\ttfamily Datarun0.\+root}\+: ~\newline
 
\begin{DoxyCode}{0}
\DoxyCodeLine{\mbox{\hyperlink{classTRATPACEventViewer}{TRATPACEventViewer}} R(\textcolor{stringliteral}{"{}Datarun0.root"{}});}
\DoxyCodeLine{R.DrawGeometry();}
\DoxyCodeLine{R.Zoom(5.0);}
\DoxyCodeLine{R.DrawTracks(0);}
\DoxyCodeLine{R.DrawNextEvent();}
\DoxyCodeLine{R.DrawNextEvent();}
\DoxyCodeLine{\textcolor{comment}{// etc.}}

\end{DoxyCode}

\doxysubsection{Detailed Description}
Class for combining reference-\/comparison results from multiple runs. 

\mbox{\hyperlink{classTKSMultiRes}{TKSMulti\+Res}}

Class for combining reference-\/comparison results from multiple runs, specifically from KSSummary data.

To use\+:
\begin{DoxyItemize}
\item Call constructor
\item Call \mbox{\hyperlink{classTKSMultiRes_ae43e4a85359436539fe486a923b433ae}{Run()}}
\item Use Set\+Out\+File\+Name to change output filenames {\itshape \mbox{[}optional\mbox{]}}
\item Call \mbox{\hyperlink{classTKSMultiRes_a525ce223bfa99b01c59a3a1f9d5781c6}{Save()}} {\itshape \mbox{[}optional\mbox{]}}
\item {\itshape Note\+: You can ajust the camera in the ribbon plot before saving if desired}
\end{DoxyItemize}

{\footnotesize\ttfamily TMacro $\ast$ TKSMulti\+Res\+::\+Generate\+Ribbon\+Macro (\begin{DoxyParamCaption}{ }\end{DoxyParamCaption})}



Generate a TMacro for recreating the ribbon plots. 

This function is called by \mbox{\hyperlink{classTKSMultiRes_a525ce223bfa99b01c59a3a1f9d5781c6}{Save()}} if a ribbon plot exists. Because TCanvas\+::\+Write() does not seem to record the \char`\"{}cut\char`\"{} options, simply writing the ribbon canvas to a TFile and then attempting to draw the ribbon canvas from the file does not display the ribbon plots correctly. ~\newline
 {\bfseries{This feature enables a user to properly open the ribbon plot interactively without needing to access the source datafiles and TKSMulti\+Res/\+TKSMulti\+Ribbons classes.}} ~\newline
 {\itshape Note\+: This was written with ROOTv5.\+34/30 and may not work with other versions.} ~\newline

{\footnotesize\ttfamily void TKSMulti\+Res\+::\+Save (\begin{DoxyParamCaption}{ }\end{DoxyParamCaption})}



Save results. 

Calling \mbox{\hyperlink{classTKSMultiRes_a525ce223bfa99b01c59a3a1f9d5781c6}{Save()}} will \+:

1) Export the current view of all existing canvases, in {\ttfamily .png} format; and

2) Write the following objects to the output file\+:


\begin{DoxyItemize}
\item The histogram canvas, as {\ttfamily TCanvas$\ast$ c\+\_\+histo}
\item The histogram itself, as {\ttfamily TH1\+D$\ast$ histo}
\item The fitted Gaussian function, as {\ttfamily TF1$\ast$ gauss\+Fit}
\item The fit result, as {\ttfamily TFit\+Result$\ast$ fit\+Result}
\item A macro for properly opening the saved ribbon plot, if one was created 
\end{DoxyItemize}

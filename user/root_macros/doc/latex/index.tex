 \doxysection*{ROOT MACROS AND CLASSES}

Instructions for using the (most useful) macros and classes in {\itshape github –$>$ duvall3 –$>$ rat-\/pac –$>$ branch collab –$>$ user –$>$ \href{https://github.com/duvall3/rat-pac/blob/collab/user/root_macros}{\texttt{ root\+\_\+macros}}}.

\DoxyHorRuler{0}
 \doxysubsubsection*{Installation}

{\itshape Note\+: These are written for $\ast$nix systems (Mac/\+Linux)}


\begin{DoxyEnumerate}
\item After git-\/cloning this repository (or downloading the individual files), run the \href{../../macro_paths.sh}{\texttt{ macro\+\_\+paths.\+sh}} script located in this directory and follow the instructions it provides. 
\item If you are using the \href{../../rootlogon.C}{\texttt{ rootlogon.\+C}} provided in this directory, then everything should now be ready. If you are using your own {\ttfamily rootlogon.\+C} elsewhere, simply append the contents of this directory’s version to yours. 
\end{DoxyEnumerate}\DoxyHorRuler{0}
 \doxysubsubsection*{Usage}

Open ROOT and run {\ttfamily .x duvall3\+Include.\+cxx} to load the macros and classes.~\newline
 For further information\+:~\newline

\begin{DoxyEnumerate}
\item If you’re currently only viewing the file {\ttfamily README.\+md}, then start with the rest of this documentation, located at {\ttfamily doc} $>$ {\ttfamily html} $>$ \href{index.html}{\texttt{ {\ttfamily index.\+html}}};~\newline

\item For documentation on the reference-\/matching algorithm, see the \href{md_ReferenceMatching.html}{\texttt{ Reference-\/\+Matching User’s Guide}}.~\newline

\item If you don’t find what you need, see the comments in the individual files; and finally,~\newline

\item If you still need assisstance after that, feel free to contact me at \href{mailto:duvall3.git@gmail.com}{\texttt{ duvall3 dot git at gmail dot com}}.
\end{DoxyEnumerate}

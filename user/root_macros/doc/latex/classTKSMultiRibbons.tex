\doxysubsection{Detailed Description}
Class for analyzing Delta\+Phi for each individual angle alongside \mbox{\hyperlink{classTKSMultiRes}{T\+K\+S\+Multi\+Res}}. 

\mbox{\hyperlink{classTKSMultiRibbons}{T\+K\+S\+Multi\+Ribbons}}

Class for making ribbon and heatmap plots, specifically from K\+S\+Summary data.

To use\+:
\begin{DoxyItemize}
\item Call constructor
\item Use Set\+Plot\+Types(0$\vert$1$\vert$2) to select desired plot(s) {\itshape \mbox{[}optional\mbox{]}}
\item Call \mbox{\hyperlink{classTKSMultiRibbons_a906466883108ae2d4ca5a75c5fb049c0}{Run()}}
\item Use Set\+Out\+File\+Name to change output filenames {\itshape \mbox{[}optional\mbox{]}}
\item Call \mbox{\hyperlink{classTKSMultiRibbons_a4618c3248f1e9996e7c3978623452043}{Save()}} {\itshape \mbox{[}optional\mbox{]}}
\item {\itshape Note\+: You can ajust the camera in the ribbon plot before saving if desired}
\end{DoxyItemize}

Plot-\/type enum options are\+:
\begin{DoxyItemize}
\item 0 = k\+Ribbons\+: ribbon plot only
\item 1 = k\+Heatmap\+: heatmap plot only
\item 2 = k\+Both\+: both plots {\itshape \mbox{[}default\mbox{]}}
\end{DoxyItemize}

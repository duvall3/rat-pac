 \doxysubsection*{Description}

This is a user’s guide for the set of software within {\itshape Tools for Reactor-\/\+Neutrino Studies in RAT-\/\+PAC} (\href{github.com/duvall3/rat-pac}{\texttt{ github.\+com/duvall3/rat-\/pac}}) that implements our algorithm for matching experimental datasets to reference distributions. See \href{index.html}{\texttt{ user/root\+\_\+macros/doc/html/index.\+html}} in this repository for more information on the entire toolset.

\DoxyHorRuler{0}
 \doxysubsection*{Procedure}

{\bfseries{Parameters}}

These instructions will make the following assumptions\+:~\newline

\begin{DoxyItemize}
\item You have already completed the {\itshape Installation} instructions given on \href{index.html}{\texttt{ the main page}}.~\newline

\item This repository is located in the directory {\ttfamily \$\+RATDIR} – often simply {\ttfamily \$\+HOME/rat-\/pac}, for example.~\newline

\item Your {\ttfamily RAT-\/\+PAC} experiment is located in the directory {\ttfamily \$\+DETECTOR} – for example, {\ttfamily DETECTOR=\$\+RATDIR/data/some\+\_\+experiment}~\newline

\item Your reference set, collected test runs, and current test run are located in the directories {\ttfamily \$\+REFDATA}, {\ttfamily \$\+TESTDIR}, and {\ttfamily \$\+TESTDATA}, respectively. For example\+:~\newline
 – {\ttfamily REFDATA=\$\+DETECTOR/\+REF}~\newline
 – {\ttfamily TESTDIR=\$\+REFDATA/\+TEST\+\_\+\+RUNS}~\newline
 – {\ttfamily TESTDATA=\$\+TESTDIR/\+Test\+Run0}~\newline
 – {\itshape Note\+: Placing {\ttfamily \$\+TESTDATA} inside {\ttfamily \$\+REFDATA} is recommended}~\newline

\item You are using a cluster or large server with at least 64 cores. If not, you will need to adjust the arguments of {\ttfamily angle\+\_\+multibatch.\+sh} (run {\ttfamily angle\+\_\+multibatch -\/h} for details).
\end{DoxyItemize}

 \doxysubsection*{Details}

\doxysubsubsection*{1\+: Run Reference Set}


\begin{DoxyItemize}
\item Run your reference simulation set in {\ttfamily \$\+DETECTOR}.~\newline
  
\item Create a directory for the reference data, and move the output there. 
\end{DoxyItemize}

{\bfseries{{\itshape Example\+:}}}

\href{\#cb1-5}{\texttt{ }}mv -\/t REF/ ReferenceRun0*
\href{\#cb1-6}{\texttt{ }}cd REF
\href{\#cb1-7}{\texttt{ }}REFDATA=\$PWD}\end{DoxyPre}

 \doxysubsubsection*{5\+: Execute Comparisons}


\begin{DoxyItemize}
\item {\bfseries{{\itshape This is where the magic happens!}}} 
\item Navigate to {\ttfamily \$\+REFDATA} and run {\ttfamily ref\+\_\+compare.\+sh} on {\itshape the relative path to} {\ttfamily \$\+TESTDATA}.~\newline
  
\item This will use \mbox{\hyperlink{classTRefMatch}{TRef\+Match}} to examine each of the extracted test distributions and find its best statistical match in the reference set. 
\item The {\ttfamily ref\+\_\+compare.\+sh} script can also accept arguments to run on an individual file, to use the Anderson-\/\+Darling test instead of Kolmogorov-\/\+Smirnov, and to look for a variable other than “phi”; its full parameters and default values are as follows\+:~\newline
 {\ttfamily ref\+\_\+compare.\+sh $<$FILE$\vert$\+DIRECTORY$>$ \mbox{[}ANDERSON\+\_\+\+TF=false\mbox{]} \mbox{[}VARNAME=phi\mbox{]}} 
\end{DoxyItemize}

{\bfseries{{\itshape Example\+:}}}


\begin{DoxyPre}{\ttfamily \href{\#cb7-1}{\texttt{ }}cd \$REFDATA
\href{\#cb7-2}{\texttt{ }}ref\_compare.sh TEST\_RUNS/TestRun0}\end{DoxyPre}
 \doxysubsubsection*{6\+: Compile Results Summary}


\begin{DoxyItemize}
\item Navigate to {\ttfamily \$\+TESTDATA}.~\newline
  
\item Open {\ttfamily ROOT} and run the macro {\ttfamily KSSummary.\+cxx}; the default parameters should work, so you can run it without arguments. This macro creates the following output files\+: 
\begin{DoxyItemize}
\item {\ttfamily KSSummary.\+root}\+: a {\itshape ROOT} file containing the full results matrix and related plots;~\newline
  
\item {\ttfamily KSSummary.\+png}\+: an exported {\itshape PNG} of the plots from the {\itshape ROOT} file;~\newline
  
\item {\ttfamily KSSummary.\+txt}\+: a nicely-\/formatted {\itshape ASCII} view of the results matrix, with column labels included.~\newline
  
\end{DoxyItemize}
\item {\itshape \mbox{[}Optional\mbox{]}} If you don’t have a graphical connection to the server or cluster, copy the {\ttfamily KSSummary} output files {\itshape (.root, .png,} and {\itshape .txt)} to your system (via, {\itshape e.\+g.,} {\ttfamily scp}).~\newline
  
\item Open the results and get ready to publish! 
\end{DoxyItemize}

 \doxysubsubsection*{7. Combine Results with Other Test Runs {\itshape \mbox{[}Optional\mbox{]}}}

If you have completed multiple test runs, you can combine their results to analyze the detector’s performance over the aggregate dataset using {\ttfamily \mbox{\hyperlink{classTKSMultiRes}{TKSMulti\+Res}}} as follows\+:~\newline

\begin{DoxyItemize}
\item Navigate to {\ttfamily \$\+TESTDIR}.~\newline

\item Open {\ttfamily ROOT}.~\newline

\item Create a \mbox{\hyperlink{classTKSMultiRes}{TKSMulti\+Res}} object.~\newline

\item If desired, adjust settings (most commonly using the {\ttfamily Set\+Ribbon()} method to turn the ribbon plot on \mbox{[}default\mbox{]} or off).~\newline

\item Call the {\ttfamily Run()} method.~\newline

\item If desired, save output using the {\ttfamily Save()} method.
\end{DoxyItemize}

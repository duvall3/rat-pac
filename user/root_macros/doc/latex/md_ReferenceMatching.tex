 \doxysubsection*{Description}

This is a user’s guide for the set of software within {\itshape Tools for Reactor-\/\+Neutrino Studies in R\+A\+T-\/\+P\+AC} (\href{github.com/duvall3/rat-pac}{\texttt{ github.\+com/duvall3/rat-\/pac}}) that implements our algorithm for matching experimental datasets to reference distributions.  \doxysubsection*{Procedure}

{\bfseries{Parameters}}

These instructions will make the following assumptions\+:~\newline

\begin{DoxyItemize}
\item You have already completed the {\itshape Installation} instructions given on \href{index.html}{\texttt{ the main page}}.~\newline

\item This repository is located in the directory {\ttfamily \$\+R\+A\+T\+D\+IR} – often simply {\ttfamily \$\+H\+O\+ME/rat-\/pac}, for example.~\newline

\item Your {\ttfamily R\+A\+T-\/\+P\+AC} experiment is located in the directory {\ttfamily \$\+D\+E\+T\+E\+C\+T\+OR} – for example, {\ttfamily D\+E\+T\+E\+C\+T\+OR=\$\+R\+A\+T\+D\+IR/some\+\_\+experiment}~\newline

\item Your reference and test dataruns are located in the directories {\ttfamily \$\+R\+E\+F\+D\+A\+TA} and {\ttfamily \$\+T\+E\+S\+T\+D\+A\+TA}, respectively. For example\+:~\newline
 – {\ttfamily R\+E\+F\+D\+A\+TA=\$\+D\+E\+T\+E\+C\+T\+OR/\+R\+EF}~\newline
 – {\ttfamily T\+E\+S\+T\+D\+A\+TA=\$\+R\+E\+F\+D\+A\+TA/\+T\+E\+ST}~\newline
 – {\itshape Note\+: Placing {\ttfamily \$\+T\+E\+S\+T\+D\+A\+TA} directly inside {\ttfamily \$\+R\+E\+F\+D\+A\+TA} is recommended}~\newline

\item You are using a cluster or large server with at least 64 cores. If not, you will need to adjust the arguments of {\ttfamily angle\+\_\+multibatch.\+sh} (run it without arguments for details).
\end{DoxyItemize}

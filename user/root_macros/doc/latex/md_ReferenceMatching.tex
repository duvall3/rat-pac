 \doxysubsection*{Description}

This is a user’s guide for the set of software within {\itshape Tools for Reactor-\/\+Neutrino Studies in R\+A\+T-\/\+P\+AC} (\href{github.com/duvall3/rat-pac}{\texttt{ github.\+com/duvall3/rat-\/pac}}) that implements our algorithm for matching experimental datasets to reference distributions. See \href{index.html}{\texttt{ user/root\+\_\+macros/doc/html/index.\+html}} in this repository for more information on the entire toolset.

 \doxysubsection*{Procedure}

{\bfseries{Parameters}}

These instructions will make the following assumptions\+:~\newline

\begin{DoxyItemize}
\item You have already completed the {\itshape Installation} instructions given on \href{index.html}{\texttt{ the main page}}.~\newline

\item This repository is located in the directory {\ttfamily \$\+R\+A\+T\+D\+IR} – often simply {\ttfamily \$\+H\+O\+ME/rat-\/pac}, for example.~\newline

\item Your {\ttfamily R\+A\+T-\/\+P\+AC} experiment is located in the directory {\ttfamily \$\+D\+E\+T\+E\+C\+T\+OR} – for example, {\ttfamily D\+E\+T\+E\+C\+T\+OR=\$\+R\+A\+T\+D\+IR/some\+\_\+experiment}~\newline

\item Your reference set, collected test runs, and current test run are located in the directories {\ttfamily \$\+R\+E\+F\+D\+A\+TA}, {\ttfamily \$\+T\+E\+S\+T\+D\+IR}, and {\ttfamily \$\+T\+E\+S\+T\+D\+A\+TA}, respectively. For example\+:~\newline
 – {\ttfamily R\+E\+F\+D\+A\+TA=\$\+D\+E\+T\+E\+C\+T\+OR/\+R\+EF}~\newline
 – {\ttfamily T\+E\+S\+T\+D\+IR=\$\+R\+E\+F\+D\+A\+TA/\+T\+E\+S\+T\+\_\+\+R\+U\+NS}~\newline
 – {\ttfamily T\+E\+S\+T\+D\+A\+TA=\$\+T\+E\+S\+T\+D\+IR/\+Test\+Run0}~\newline
 – {\itshape Note\+: Placing {\ttfamily \$\+T\+E\+S\+T\+D\+A\+TA} inside {\ttfamily \$\+R\+E\+F\+D\+A\+TA} is recommended}~\newline

\item You are using a cluster or large server with at least 64 cores. If not, you will need to adjust the arguments of {\ttfamily angle\+\_\+multibatch.\+sh} (run {\ttfamily angle\+\_\+multibatch -\/h} for details).
\end{DoxyItemize}

 \doxysubsubsection*{5\+: Execute Comparisons}


\begin{DoxyItemize}
\item {\bfseries{{\itshape This is where the magic happens!}}} 
\item Navigate to {\ttfamily \$\+R\+E\+F\+D\+A\+TA} and run {\ttfamily ref\+\_\+compare.\+sh} on {\itshape the relative path to} {\ttfamily \$\+T\+E\+S\+T\+D\+A\+TA}.~\newline
  
\item This will use \mbox{\hyperlink{classTRefMatch}{T\+Ref\+Match}} to examine each of the extracted test distributions and find its best statistical match in the reference set. 
\item The {\ttfamily ref\+\_\+compare.\+sh} script can also accept arguments to run on an individual file, to use the Anderson-\/\+Darling test instead of Kolmogorov-\/\+Smirnov, and to look for a variable other than “phi”; its full parameters and default values are as follows\+:~\newline
 {\ttfamily ref\+\_\+compare.\+sh $<$F\+I\+L\+E$\vert$\+D\+I\+R\+E\+C\+T\+O\+RY$>$ \mbox{[}A\+N\+D\+E\+R\+S\+O\+N\+\_\+\+TF=false\mbox{]} \mbox{[}V\+A\+R\+N\+A\+ME=phi\mbox{]}} 
\end{DoxyItemize}

{\bfseries{{\itshape Example\+:}}}


\begin{DoxyPre}{\ttfamily \label{_cb7-1}%
cd \$REFDATA
\label{_cb7-2}%
ref\_compare.sh TEST\_RUNS/TestRun0}\end{DoxyPre}
 \doxysubsubsection*{6\+: Compile Results Summary}


\begin{DoxyItemize}
\item Navigate to {\ttfamily \$\+T\+E\+S\+T\+D\+A\+TA}.~\newline
  
\item Open {\ttfamily R\+O\+OT} and run the macro {\ttfamily K\+S\+Summary.\+cxx}; the default parameters should work, so you can run it without arguments. This macro creates the following output files\+: 
\begin{DoxyItemize}
\item {\ttfamily K\+S\+Summary.\+root}\+: a {\itshape R\+O\+OT} file containing the full results matrix and related plots;~\newline
  
\item {\ttfamily K\+S\+Summary.\+png}\+: an exported {\itshape P\+NG} of the plots from the {\itshape R\+O\+OT} file;~\newline
  
\item {\ttfamily K\+S\+Summary.\+txt}\+: a nicely-\/formatted {\itshape A\+S\+C\+II} view of the results matrix, with column labels included.~\newline
  
\end{DoxyItemize}
\item {\itshape \mbox{[}Optional\mbox{]}} If you don’t have a graphical connection to the server or cluster, copy the {\ttfamily K\+S\+Summary} output files {\itshape (.root, .png,} and {\itshape .txt)} to your system (via, {\itshape e.\+g.,} {\ttfamily scp}).~\newline
  
\item Open the results and get ready to publish! 
\end{DoxyItemize}

 \doxysubsubsection*{7. Combine Results with Other Test Runs {\itshape \mbox{[}Optional\mbox{]}}}

If you have completed multiple test runs, you can combine their results to analyze the detector’s performance over the aggregate dataset using {\ttfamily \mbox{\hyperlink{classTKSMultiRes}{T\+K\+S\+Multi\+Res}}} as follows\+:~\newline

\begin{DoxyItemize}
\item Navigate to {\ttfamily \$\+T\+E\+S\+T\+D\+IR}.~\newline

\item Open {\ttfamily R\+O\+OT}.~\newline

\item Create a \mbox{\hyperlink{classTKSMultiRes}{T\+K\+S\+Multi\+Res}} object.~\newline

\item If desired, adjust settings (most commonly using the {\ttfamily Set\+Ribbon()} method to turn the ribbon plot on \mbox{[}default\mbox{]} or off).~\newline

\item Call the {\ttfamily Run()} method.~\newline

\item If desired, save output using the {\ttfamily Save()} method.
\end{DoxyItemize}

{\bfseries{{\itshape Example\+:}}}


\begin{DoxyPre}{\ttfamily \label{_cb11-1}%
cd \$TESTDIR
\label{_cb11-2}%
root}\end{DoxyPre}
 
\begin{DoxyPre}{\ttfamily \label{_cb12-1}%
\mbox{\hyperlink{classTKSMultiRes}{TKSMultiRes}} M;
\label{_cb12-2}%
//M.SetRibbon(kFALSE); // deactivate ribbon plot if desired
\label{_cb12-3}%
M.Run();
\label{_cb12-4}%
M.Save();}\end{DoxyPre}
